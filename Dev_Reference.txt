If you want complete feature lists, go to manuscript in scope section.

Features:
- Fish Species Identification via YOLO for preprocessing and CNN for actual identification.
- Identification result would include calculated confidence scores, alternative candidates, and fish conservation status.
- Offline Species Reference Library
- Map w/ Restricted zones scraped from government data source
- Digital Catch Logging
- Notifications regarding regulations, distance from restricted zones, and new zone restrictions.
- View Visual Data Summary
- Mobile App

Scope:
AI-based identification of selected fish species: The system can identify a species of a fish if it exists inside its dataset.
Offline fish species library.
GPS-based location monitoring.
Map of selected government-provided restricted areas.
Geofencing and location-based warnings.
Notifications about selected fishing regulations and closed seasons.
User-friendly interface for municipal fishers.
